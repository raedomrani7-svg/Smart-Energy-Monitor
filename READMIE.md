# Smart Energy Monitor ⚡

## About the Project

Smart Energy Monitor is a beginner Python project
that analyzes weekly energy consumption data.

## Features

- Weekly energy consumption analysis
- Average, minimum, and maximum calculations
- Data visualization using Matplotlib
- Simple next-day consumption estimation
- Energy consumption classification
- Detection of high-consumption days

## Technologies

- Python
- Matplotlib
- Data Analysis
- VS Code

## Current Status

This project uses simulated energy consumption data.
The prediction is based on a simple moving average,
not a trained Machine Learning model.

## Future Improvements

- Import real energy consumption data
- Build a Machine Learning prediction model
- Add an interactive dashboard
- Explore intelligent energy management
